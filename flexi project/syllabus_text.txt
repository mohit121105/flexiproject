Suggested Pedagogy:
∩é╖ Short concept lectures followed by live demonstrations.
∩é╖ Lab-based coding sessions for each framework and unit.
∩é╖ Guided notebook exercises for single-agent and multi-agent workflows.
∩é╖ Case-based learning using real automation scenarios.
∩é╖ Mini-projects and a capstone-style integration task across tools and frameworks.
Evaluation/Assessment Methods:
∩é╖ Quizzes on concepts and framework architecture.
∩é╖ Laboratory assignments for each unit.
∩é╖ Coding exercises on agents, tools, and automations.
∩é╖ One or more mini-projects integrating multiple frameworks.
∩é╖ Final project/demo with viva or presentation.
Course Outcomes (CO):
CO1: Implement single AI agents using the OpenAI Agents SDK with memory, tracing,
and tool integration features for handling user tasks.
CO2: Develop multi-agent workflows with role-based agents, task delegation, guardrails,
and handoff mechanisms using the OpenAI Agents SDK.
CO3: Build agentic applications using AutoGen and LangGraph frameworks with multi-
model agents, custom tools, and workflow visualization.
CO4: Implement AI workflows using CrewAI and MCP by integrating predictive analytics,
external tools, and MCP-compatible services.
CO5: Create automation workflows in n8n by integrating AI services with Gmail, Google
Sheets, and Google Calendar for task automation and structured data handling.
